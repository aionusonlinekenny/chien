Encrypt (mã hóa):
  - Cho file "cfg.json" vào thư mục "in"
  - Chạy encrypt.bat (encrypt_confuse.bat để mã hóa x9)
  - Thu được file "cfg.cfg" trong thư mục "out"

Decrypt (giải mã):
  - Cho file "cfg.cfg" vào thư mục "in"
  - Chạy decrypt.bat
  - Thu được file "cfg.json" trong thư mục "out"
